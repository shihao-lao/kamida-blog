# 此项目为使用next+tailwind所搭建的个人博客用于记录前端学习中所遇到的一些问题,并且进行解决

## 技术栈

- **框架**：Next.js 14（App Router）
- **样式**：Tailwind CSS + PostCSS
- **语言**：JavaScript（可扩展 TypeScript）
- **字体优化**：next/font（Geist 字体）
- **部署平台**：Vercel
- **代码规范**：ESLint + jsconfig.json

[👉 在线访问博客](https://kamida-blog.vercel.app)

## 个人心得
- 在开发这个博客的过程中，我深刻体会到：

Next.js App Router + Tailwind CSS 的组合能极大提升开发效率，同时保持代码简洁和性能优秀。
记录学习过程中的“踩坑”与“填坑”过程，不仅帮助自己加深理解，也能为后来者提供参考。
技术博客不是单纯的知识堆砌，而是将复杂概念用通俗易懂的方式表达出来，这本身就是一次很好的技术输出练习。
持续更新、保持热情，是个人博客最宝贵的价值。
